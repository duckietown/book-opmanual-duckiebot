# Setting up GitHub 

In addition to the GitHub account you'll need to create an SSH key, to seamlessly access GitHub through terminal without having to enter the password each time. 

Follow the official GitHub documentation to create a SSH Key [Link](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent).  

Once you have a GitHub username and SSK key associated with your account, you can continue on to the next page to set up your Duckietown account.
